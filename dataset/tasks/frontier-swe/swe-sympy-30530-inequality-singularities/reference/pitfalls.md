# 常见错误

1. **只给 `1/x` 打补丁**：分母可能是多个因子的乘积（`1/x + 1/(x-1)`），也可能不可约（`1/sin(x)`）；按表达式形态特判会在这些场景失败。
2. **在最终结果上追补 `Ne`**：解集是区间并集与 `Ne` 的交集，直接附加条件可能改变解集形状或漏掉浮点系数场景；应在归约前保留分母约束。
3. **忽略"相减后为 0"的路径**：`1/x <= 1/x` 相减后 `rv` 不为 `None`，原实现的约束块在该路径不执行；把约束处理放在错误的分支会漏掉它。
4. **只处理能解出单点的分母**：`sin(x) = 0` 解出的是周期集合，无法表示为生成元的有限取值；必须回退到保留 `d != 0`。
5. **丢失重数信息**：`1/x**2 < (x+1)/x**2` 中分母重数在相减后可能下降，但零点仍然失效，需保持约束。
6. **忘记非 Symbol 生成元**：`solve_univariate_inequality` 收到 `RandomSymbol` 时应先转为实 `Dummy`，否则返回 `ConditionSet` 与显式区间不一致。
