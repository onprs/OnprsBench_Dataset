# 常见错误

1. **用 `\d` 拼正则**：Python 的 `\d` 匹配任意 Unicode 十进制数字，`<int:a>` 仍会接受 `١٢٣`。必须显式使用 `[0-9]`。
2. **只在解析侧修补**：`to_url` 仍不校验，模型可以构建出 `-123`（未开启 `signed`）、越界值，导致 build 出的 URL 与 match 语义不一致。
3. **`fixed_digits` 继续把负号计入位数**：`-0123` 应是 4 位数而非 5 位；相应地 `to_url` 的补零宽度要按正负号调整，否则负数构建出错。
4. **用固定小数位格式化**：强制 6 位小数之类的做法会截断合法取值，并且仍然要单独处理科学计数法。正确方向是信任 `str(value)`，仅在结果含 `e` 时展开。
5. **遗漏 `inf`/`nan` 的构建校验**：`to_url` 接受 `float("inf")` 会输出 `inf`，必须显式拒绝；解析侧的溢出值也要在转换后检查。
6. **破坏既有合法取值**：`0.00001`、`10000000000000000.0`、`-0.0`、前导零 `0500` 等都应保持可用；修改补零与格式化逻辑时逐一确认。
