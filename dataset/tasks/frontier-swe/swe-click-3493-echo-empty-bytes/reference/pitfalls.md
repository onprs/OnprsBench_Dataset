# 常见错误

1. **只处理 `b""` 而漏掉 `bytearray(b"")`**：两者都是假值，同样触发该 bug。
2. **在写文件处特判**：在 `file.write(out)` 前把 str 转回 bytes 属于打补丁，会掩盖类型语义并影响其他路径。
3. **改变 None 的行为**：`echo(None)` 的既有语义是输出空内容（配合 `nl` 输出换行），修复时必须保持。
4. **遗漏非 str/bytes 对象分支**：`echo(123)` 等调用依赖 `str(message)` 转换，重写分支结构时要保留。
5. **忽视函数签名变更的连锁影响**：上游把 `message` 的注解从 `t.Any | None` 改为 `object`；签名层面保持等价语义即可，不必照抄，但不能引入不兼容。
