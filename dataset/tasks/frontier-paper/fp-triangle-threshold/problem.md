# 随机顺序边流上的阈值三角计数

## 背景

给定一个简单无向图 $G$ 的 $m$ 条边按某一顺序到达（每条边只出现一次），以及一个正整数阈值 $Q$。需要按如下过程处理边流：

维护已读入边的邻接表 $A$（初始为空）、累计三角形计数 $t = 0$ 与已读长度 $S = 0$。对到达的边 $e = (u, v)$ 依次执行：

1. 令 $t \leftarrow t + |N_A(u) \cap N_A(v)|$，其中 $N_A(x)$ 是 $A$ 中与 $x$ 相邻的顶点集合（这一步统计 $e$ 与 $A$ 中已有边共同闭合的三角形数；计数时 $e$ 尚未加入 $A$）；
2. 把 $e$ 加入 $A$；
3. 令 $S \leftarrow S + 1$；
4. 若 $t \ge Q$，停止处理后续边。

若读完全部 $m$ 条边仍有 $t < Q$，则 $S = m$。最终输出停止长度 $S$ 与估计值

$$\hat{T} = Q \cdot \frac{m^3}{S^3}.$$

## 输入格式

第一行一个整数 $T$（$1 \le T \le 100$，表示测试用例数）。

每个用例：

- 第一行两个整数 $m$、$Q$（$1 \le m \le 2 \times 10^5$，$1 \le Q \le 10^{18}$）；
- 接下来 $m$ 行，每行两个整数 $u$、$v$（$0 \le u, v \le 10^9$，$u \ne v$），表示一条连接顶点 $u$ 与 $v$ 的边。

同一用例中任意两条边互不相同（看成无向边）；所有用例的 $m$ 之和不超过 $2 \times 10^5$。

## 输出格式

每个用例输出一行，包含三个整数 $S$、$p$、$q$，用一个空格分隔，要求：

- $S$ 为按上述过程实际处理（读入并插入）的边数；
- $p/q$ 是 $\hat{T}$ 的既约分数表示，即 $\gcd(p, q) = 1$、$q \ge 1$、$p \ge 0$。

## 示例

输入：

```
5
5 1
0 1
1 2
0 2
0 3
1 3
3 1
0 1
1 2
2 3
6 2
0 1
1 2
0 2
0 3
1 3
2 3
3 1000000000000000000
0 1
1 2
2 3
3 2
0 1
0 2
1 2
```

输出：

```
3 125 27
3 1 1
5 432 125
3 1000000000000000000 1
3 2 1
```

## 说明

- 即使过程提前停止，输入中仍会给出完整的 $m$ 条边；停止后的边不得参与计数，且 $S$ 只统计停止前处理过的边。
- 阈值 $Q$、估计值分子分母都可能超出 32 位整数范围，请使用 64 位或更大整数并注意约分。
- 允许使用任意正确且足够高效的实现；同一用例内不会出现重边或自环。
