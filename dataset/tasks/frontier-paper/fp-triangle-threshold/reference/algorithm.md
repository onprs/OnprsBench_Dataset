# 参考解与答案锚点

## 来源结论（锚点）

来源论文：*Scalable Triangle Counting: The Threshold Algorithm*（arXiv:2609.15848，2026-09-14）。

- 论文的 **Algorithm 1（阈值算法）**：按随机顺序读取边，维护已读边的邻接结构；每读到一条边，统计该边闭合的三角形数并累加；累计数首次达到阈值 $Q$ 时停止；输出估计 $\hat{T} = Q(m/S)^3$，其中 $m$ 为流长度、$S$ 为停止长度。
- 论文的 **定理 1.1 / 定理 2.1** 给出该估计在随机顺序边流与 $\eta \le T^{2/3}$ 条件下的 $(1 \pm \varepsilon)$ 保证，并给出停止长度 $S$ 的界。本题只要求逐步复现算法的确定性行为，不涉及概率保证。

## 参考实现说明

`judge_assets/reference_solution.cpp` 按定义逐步模拟：

1. 用哈希表把输入顶点编号压缩为连续下标，邻接关系用哈希集合维护；
2. 插入边 $(u,v)$ 前，遍历 $N_A(u)$ 与 $N_A(v)$ 中较小的一侧，统计出现在另一侧中的顶点数，累加到 $t$；
3. 插入边、$S \leftarrow S+1$，若 $t \ge Q$ 则置停止标志（继续消费剩余输入行，但不再模拟）；
4. 输出 $S$ 及 $Q \cdot m^3 / S^3$ 的既约分数（用 `__int128` 保存中间乘积后约分）。

## 为什么答案不是 AI 自证

- 题目要求的是对已发表算法（Algorithm 1）的**确定性逐步模拟**，输出由过程本身唯一决定；参考实现是该过程的形式转换。
- 参考实现已与独立编写的暴力模拟（直接按定义用集合交求公共邻居）在 149 个生成用例上逐字对拍一致。
- 输出为既约分数，由过程与约分规则唯一确定，不存在多解。
