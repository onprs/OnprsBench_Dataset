# 常见错误（pitfalls）

1. **用近似方法充当精确解**：熵正则化 Sinkhorn/Greenkhorn 只能在容差内近似，输出的实数舍入后可能偏离最优整数费用；本题要求精确值。
2. **对偶势不可行**：匈牙利算法中更新势时若范围或符号写错，会让增广路失效或得到次优值；注意保持 $u_i + v_j \le C_{ij}$，并在增广后对已访问列减去 $\delta$、对已访问行的行势加上 $\delta$。
3. **计数与索引**：e-maxx 风格实现使用 1-based 的 `p[0..n]` 与 0-based 矩阵，混用会下标越界或错位。
4. **只用对偶势求和**：$\sum u_i + \sum v_j$ 在实现正确时等于最优值，但如果势更新有误会得到错误值；用重建匹配直接求费用更稳健，也可作为自检。
5. **大费用溢出**：单条费用不超过 $10^6$、总费用不超过 $4 \times 10^8$，但中间势与 $\delta$ 的加减仍建议使用 64 位整数。
6. **结构化实例的退化**：植入排列或对角便宜的矩阵在贪心后大量零费用边，注意增广路扫描的边界（`delta` 初始值应足够大）。
7. **复杂度退化**：使用通用的最小费用流（每次 SPFA 增广）在 n = 400 稠密图上会偏慢；建议使用带势的增广或专用匈牙利实现。
