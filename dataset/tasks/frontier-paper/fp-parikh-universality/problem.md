# 二进制 Parikh 矩阵语言的普遍性指数

## 记号与定义

固定字母表 $\Sigma = \{a, b\}$。

对词 $w \in \Sigma^*$：

- $|w|_a$、$|w|_b$：$w$ 中 $a$、$b$ 的出现次数；
- $|w|_{ab}$：满足 $i < j$、$w_i = a$、$w_j = b$ 的下标对 $(i, j)$ 的个数（即 $w$ 作为子序列包含的 $ab$ 对数）。

对非负整数 $A, B, C$，定义**二进制 Parikh 矩阵语言**

$$L(A,B,C) = \{\, w \in \Sigma^* \;:\; |w|_a = A,\ |w|_b = B,\ |w|_{ab} = C \,\}.$$

保证输入中 $0 \le C \le A \cdot B$（此时 $L(A,B,C)$ 非空）。

**词的普遍性指数**：词 $w$ 的普遍性指数 $\iota(w)$ 是最大的非负整数 $k$，使得 $\Sigma$ 上每个长度为 $k$ 的词都是 $w$ 的子序列（子序列指删除若干字符后得到的词，不要求连续）。

**语言的两个普遍性指数**（$L$ 非空）：

- **存在指数** $\iota_{\exists}(L)$：最大的 $k$，使得存在 $w \in L$ 满足 $\iota(w) \ge k$；
- **全称指数** $\iota_{\forall}(L)$：最大的 $k$，使得每个 $w \in L$ 都满足 $\iota(w) \ge k$。

## 输入格式

第一行一个整数 $T$（$1 \le T \le 5000$）。

接下来 $T$ 行，每行三个整数 $A$、$B$、$C$，满足 $0 \le A, B \le 10^{18}$ 与 $0 \le C \le A \cdot B$。

## 输出格式

共 $T$ 行，第 $i$ 行输出两个整数：$\iota_{\exists}(L(A,B,C))$ 与 $\iota_{\forall}(L(A,B,C))$，以一个空格分隔。

## 示例

输入：

```
4
2 2 2
3 3 3
2 2 0
0 0 0
```

输出：

```
2 2
3 2
1 1
0 0
```

## 说明

- 参数可达 $10^{18}$，需要在常数时间内完成每个三元组的计算；基于枚举词或逐 $k$ 检查的做法无法通过规模测试。
- 输入保证语言非空；不需要处理 $C > A \cdot B$ 的情形。
