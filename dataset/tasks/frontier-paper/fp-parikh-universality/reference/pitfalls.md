# 常见错误（pitfalls）

1. **阈值差一**：存在指数的条件是 $\binom{k}{2} \le m$，即 $k(k-1)/2 \le m$。把 $\binom{k}{2}$ 误算成 $k(k+1)/2$、$k^2/2$ 或 $\binom{k+1}{2}$，会在阈值取等时整体偏一档。
2. **忽略 $AB-C$**：只检查 $C \ge \binom{k}{2}$ 而漏掉 $AB-C \ge \binom{k}{2}$。$AB-C$ 是 $|w|_{ba}$（因为对二进制词有 $|w|_{ab} + |w|_{ba} = |w|_a \cdot |w|_b$），两端都不超过阈值才能保证存在这样的词。
3. **全称指数分档顺序**：定理 4.5 是"3 不成立再看 2，2 不成立再看 1"；直接独立判断各档会错（例如 3 的条件不成立但满足 2 与 1 的条件时，答案是 2）。
4. **整除条件写反**：3 档要求 $A \nmid C$ 且 $B \nmid C$；写成 $A \mid C$ 会把最高档判反。注意 $C=0$ 时任何正整数都整除 0，因此 3 档不成立。
5. **$m > \max(A,B)$ 与 $m \ge \max(A,B)$**：3 档是严格大于。
6. **空参数情形**：$A=0$ 或 $B=0$ 时两个指数都是 0；$A=B=0$ 时语言只含空词，同样为 0。不要对 $A=0$ 做除法或取模。
7. **大整数溢出**：$A \cdot B$ 可达 $10^{36}$，注意使用大整数或 $128$ 位整型；用 64 位会溢出。
8. **超线性实现**：对每个用例从 $k=0$ 开始递增检查，在 $A,B \sim 10^{18}$ 时会超时；应使用整数平方根一次求出存在指数的上界。
