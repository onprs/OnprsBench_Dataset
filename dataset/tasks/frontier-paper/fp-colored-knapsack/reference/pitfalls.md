# 常见错误（pitfalls）

1. **删除负收益物品**：负收益物品可能是必要分隔符。删除它们会破坏颜色可行性，使原本可行的同色高收益物品无法同时选取，结果偏低。
2. **误判颜色可行性**：只要数量最多的颜色不超过其余颜色之和加一即可行；把"同色两件"当作可行（两件同色物品相邻）或要求每种颜色至多一件都会错。
3. **颜色计数重置遗漏**：按颜色排序处理时，换色瞬间当前颜色的计数必须清零；选入新颜色的第一件物品时应用 $a=0$ 参与 $d$ 的更新，否则会把不同颜色的计数错误地累加到同一个"当前颜色"上。
4. **主色数 $d$ 的更新写错**：选入物品后新主色数应为 $d' = \max(d, a+1)$；在 $a = d$ 时加一，$a < d$ 时不变。
5. **空集与容量 0**：空集收益为 0；容量为 0 时只能选重量为 0 的物品（本题重量至少为 1，因此答案为 0）。
6. **只在小规模枚举**：$n = 28$ 时 $2^{28}$ 枚举不可行；需要伪多项式或剪枝做法。
7. **收益下界**：答案至少为 0（空集可行），不要输出负值。
