# 参考解与答案锚点

## 来源结论（锚点）

来源论文：*A tight 1/3-approximation algorithm and fully polynomial-time approximation schemes for the Colored Knapsack Problem*（arXiv:2609.17713，2026-09-15）。

- **颜色可行性刻画**（论文第 1 节式 (1.1)/(1.2)，引用 Borges 等）：子集 $S$ 存在相邻异色的排列，当且仅当对每种颜色 $c$ 有 $|S_c| \le |S| - |S_c| + 1$；等价地，出现次数最多的颜色满足 $2\max_c |S_c| \le |S| + 1$。
- **状态减少**（论文第 4 节）：处理按颜色排序的物品时，部分解的颜色可行性由三元组（已选总数 $t$、某个主色已选数 $d$、当前颜色已选数 $a$）与剩余物品完全决定；同三元组下重量更小的部分解支配重量更大的部分解。
- 论文的精确 DP（原文 Algorithm 4.1，收益索引）与本题参考实现的状态设计一致；论文同时证明负收益物品可能出现在最优解中（用于充当分隔符）。

## 参考实现说明

`judge_assets/reference_solution.cpp` 使用该状态的**容量索引**变体：

- 将物品按颜色排序，使同色物品连续；
- 状态 $dp[t][d][a][w]$ = 当前最大收益，其中 $t$ 为已选总数、$d$ 为已出现的最大同色数、$a$ 为当前颜色已选数、$w$ 为已用容量；
- 逐个物品转移：不选时若颜色变化则令 $a \leftarrow 0$；选入时同理先清零再自增，并令 $d \leftarrow d + [a = d]$；
- 最终在所有满足 $2d \le t+1$ 的状态上取最大收益，与空集的收益 $0$ 比较。

复杂度为 $O(n^4 b)$ 量级（常数受 $d \le t$、$a \le d$ 限制），在 $n=28$、$b=300$ 下可行。

## 为什么答案不是 AI 自证

- 颜色可行性刻画与状态减少均来自论文中已发表、可复核的结论；容量索引变体只是同一状态空间的实现方式。
- 参考实现已与独立暴力枚举（枚举全部子集并按定义检查可行性）在 1500 组小用例与 80 组中等用例上逐行对拍一致。
- 最优值本身是确定性的整数，不存在多解或主观评分。
