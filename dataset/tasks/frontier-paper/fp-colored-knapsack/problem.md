# 彩色背包问题的最优值

## 问题

有 $n$ 件物品，背包容量为 $b$。第 $i$ 件物品有重量 $w_i$、收益 $p_i$（可为负）和颜色 $c_i$。

选择一个子集 $S$，满足：

1. **容量**：$\sum_{i \in S} w_i \le b$；
2. **颜色可行性**：$S$ 中的物品可以排成一个序列，使相邻两件物品颜色不同。

求可行子集的最大总收益 $\sum_{i \in S} p_i$。空集的收益为 $0$，因此答案不小于 $0$。

> 说明：颜色可行性等价于对每种颜色 $c$ 都有 $|S_c| \le |S| - |S_c| + 1$，其中 $S_c$ 是 $S$ 中颜色为 $c$ 的物品集合；也等价于出现次数最多的颜色满足 $2\max_c |S_c| \le |S| + 1$。

## 输入格式

第一行一个整数 $T$（$1 \le T \le 50$）。

每个用例：

- 第一行两个整数 $n$、$b$（$1 \le n \le 28$，$0 \le b \le 300$）；
- 接下来 $n$ 行，每行三个整数 $w_i$、$p_i$、$c_i$（$1 \le w_i \le 300$，$-100 \le p_i \le 100$，$0 \le c_i \le 10^9$）。

颜色编号只用于区分颜色类，不要求连续或有序。

## 输出格式

每个用例输出一行，一个整数：最大总收益。

## 示例

输入：

```
5
3 10
5 4 0
5 5 1
5 6 2
2 10
5 3 0
5 7 0
3 10
4 5 0
4 5 0
4 5 1
2 5
3 -4 0
3 -4 1
5 10
2 3 0
2 3 0
2 3 0
3 -1 1
3 -1 2
```

输出：

```
11
7
10
0
5
```

## 说明

- 收益可以为负；负收益物品有时需要作为"分隔符"参与，才能让更多同色高收益物品变得颜色可行。不能直接删除负收益物品。
- 同一颜色的多件物品不能单独凑在一起：例如两件同色物品的子集不可行（数量关系不满足）。
- 允许使用任意正确算法；伪多项式动态规划、分支限界或整数规划均可用，但需在时限内完成。
