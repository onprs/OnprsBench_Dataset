# 常见错误（pitfalls）

1. **把"缺失子串"误解为"缺失后缀"**：$w$ 缺失指 $w$ 在 $S$ 中任何位置都不出现；只比较后缀会漏掉大量出现位置。
2. **字典序与长度顺序混淆**：必须先最小化长度，再在最短者中取字典序最小；直接取字典序最小的缺失串（例如字母表里最小但很长的串）会答错。
3. **BFS 字母顺序**：在后缀自动机上做 BFS 时，若转移的检查顺序不是 $a, b, \ldots$，得到的最短缺失串不保证字典序最小；同时要按 BFS 分层顺序访问，深度优先会漏掉更短的候选。
4. **σ = 1 或存在未出现字母**：此时最短缺失串长度为 1（或 σ=1 时长度 n+1，输出 $n+1$ 个 a），不要假设答案长度不超过 n。
5. **后缀自动机转移存储**：n 至 2e5 时状态数接近 2n，用数组存整张转移表要注意内存；用哈希表或压缩转移时注意 clone 状态的复制语义。
6. **输出不是子串的情形**：答案可能包含未在 $S$ 中相邻出现的字母组合，勿用"取两个相邻字符"之类的启发式。
