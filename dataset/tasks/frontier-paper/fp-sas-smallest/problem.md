# 字典序最小的最短缺失子串

## 定义

给定整数 $\sigma$（$1 \le \sigma \le 26$）与字母表 $\Sigma = \{c_0, c_1, \ldots, c_{\sigma-1}\}$，其中 $c_i$ 是第 $i+1$ 个小写字母（$c_0 = a$，$c_1 = b$，依此类推）。给定字符串 $S$（字符均在 $\Sigma$ 内）。

- 称字符串 $w$（$w$ 的字符也取自 $\Sigma$）**缺失**于 $S$，当且仅当 $w$ 不是 $S$ 的子串。
- 称缺失串 $w$ 是 $S$ 的**最短缺失子串**，当且仅当不存在长度严格小于 $|w|$ 且缺失于 $S$ 的串。
- 若最短缺失子串不唯一，取**字典序最小**者（按 $c_0 < c_1 < \cdots$ 比较）。

本题要求对每个测试用例求出唯一的"字典序最小的最短缺失子串"。

## 输入格式

第一行一个整数 $T$（$1 \le T \le 100$）。

每个用例：

- 第一行两个整数 $n$、$\sigma$（$1 \le n \le 2 \times 10^5$，$1 \le \sigma \le 26$）；
- 第二行一个长度为 $n$ 的字符串 $S$，字符为前 $\sigma$ 个小写字母。

所有用例的 $n$ 之和不超过 $2 \times 10^5$。

## 输出格式

每个用例输出一行：该用例的字典序最小最短缺失子串。

## 示例

输入：

```
6
1 1
a
4 2
abba
5 2
aabaa
26 26
abcdefghijklmnopqrstuvwxyz
8 2
aababaab
5 3
ababc
```

输出：

```
aa
aa
bb
aa
bb
aa
```

## 说明

- 当 $\sigma = 1$ 时答案形如 $a^{n+1}$，请注意输出长度可以超过 $n$。
- 若某个字母未在 $S$ 中出现，答案即为该字母中最小的一个。
- 允许使用任意正确且足够高效的实现；所有用例的规模之和保证线性或近线性做法可在时限内完成。
