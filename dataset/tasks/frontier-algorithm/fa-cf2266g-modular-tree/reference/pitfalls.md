# 常见错误（judge 参考）

1. 未发现每个节点的可达值恰为等差数列 $(a_i + g_i x) \bmod b_i$，试图直接搜索可达状态。
2. gcd 递推漏项：$g_u = \gcd(b_u, S_u, \{g_v : v \text{ 为非固定子节点}\})$ 中漏掉 $b_u$、子节点初始值之和 $S_u$ 或子节点的 $g_v$。
3. 把固定子节点（$g_v = b_v$，其值恒为 $a_v$）也当成可变来源参与 gcd。
4. 未论证各节点的最大可达值可以同时取到（先固定父节点，再在子树内操作不影响父节点），因而不敢直接求和。
5. 叶子节点的 $g = b$ 处理错误；取最大值时整除方向写错（应为 $a_i + \left\lfloor\frac{b_i-1-a_i}{g_i}\right\rfloor g_i$）。
6. 求和与中间量溢出：$\sum b_i$ 级别到 $2\cdot10^{14}$，需要 64 位整数。
