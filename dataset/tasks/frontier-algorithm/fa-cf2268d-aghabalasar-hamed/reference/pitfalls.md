# 常见错误（judge 参考）

1. 未发现最短路的形状：至多一次左移、之后连续右移（$L, R, R, \ldots, R, L$ 形式），试图对每对 $(i,j)$ 做 BFS。
2. 求 $R_i$（右侧第一个满足 $p_j > p_i$ 的位置）时用暴力扫描，或忘记不存在时取 $n+1$。
3. 计算两步内可达的位置数 $c_2$ 时重复计数 $R_{R_i}$，或漏掉"被标记位置"集合的维护。
4. 分块边界处理错误：块尾 $r$ 满足 $R_r = n+1$，块内 dp 的传递方向与块尾的前缀关系写错。
5. 求和需要 64 位整数（答案量级可达 $O(n^3)$）。
6. 把不可达时的 $f(i,j)=0$ 与 $i=j$ 的 0 距离混淆处理，例如把不可达记成无穷大后又忘掉转换，导致总和偏大。
