# 常见错误（judge 参考）

1. 忽略"操作保持元素间相对大小关系"这一不变量，试图搜索操作序列或直接对子序列做模拟。
2. $dp[x][y]$ 的转移分支写反：每个质因子都整除 $x$ 时是 $dp[x-1][y-1]$，否则是 $dp[x][y-1]$；递推顺序必须按 $y-x$ 递增、$x$ 递增。
3. 子序列计数错误：最小值和最大值出现次数需乘 $(2^{c_x}-1)(2^{c_y}-1)$，中间值可选 $2^{\text{区间内出现次数}}$；端点同值时要单独用 $2^{c_v}-1$。
4. 直接沿用 Easy Version 的 $O(M^2)$ 建表与 $O(n^2)$ 统计（$M$ 到 $3\cdot10^5$），时间与内存都不可行。
5. Hard Version 压缩行时未合并相邻同值段，或 blocker 列表生成方向错误，导致某些 $dp$ 断点丢失。
6. 幂次与取模预处理越界（指数是区间内出现次数，不是下标）；答案取模前出现负值。
