# 常见错误（judge 参考）

1. 未利用"子树对应连续区间"的性质，直接枚举所有树（$C_n$ 爆炸）。
2. 按位独立统计时两种情况处理混用：整体 XOR 的该位为 1 时每条边恰好贡献一次；为 0 时需要统计"子数组 XOR 该位为 1"的个数并乘 2。
3. 区间出现次数权重推导错误：固定区间长度 $l$ 时权为 $C_l C_{n-l}$（Catalan 数），漏掉"断开后剩余部分形成新树"的计数。
4. 前缀 XOR 自相关 $R_l$ 与 $D_l$ 的换算写错（$D_l = \frac{n+1-l-R_l}{2}$），或忘了等值与异值贡献分别是 $+1$ 与 $-1$。
5. 每个 bit 都做一次逆 NTT，或未利用 Parseval 恒等式做加权和，常数过大超时。
6. 边界条件：只统计长度 $1 \le l \le n-1$ 的区间（排除整个数组）；$n=1$ 时答案为 0。
