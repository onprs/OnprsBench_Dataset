# 常见错误（judge 参考）

1. 未利用按位与对异或的分配律（$\text{XOR}(a_i \& m) = \text{XOR}(a_i) \& m$），直接枚举区间，复杂度 O(n²) 以上。
2. 未把区间最大值与笛卡尔树的 LCA 对应；或对相等值的合并方式不一致，导致"哪个节点代表区间最大值"判断错误。
3. 可行性检查漏掉排除点对 $(v-1, v)$：它代表被禁止的单元素区间 $[v, v]$，会让每个满足 $a_v \& M = M$ 的节点误报为可行。
4. 频率数组只记"是否存在"而不用计数。相同前缀异或值可能出现在多个下标，用布尔数组会在端点配对时漏解。
5. 小到大合并方向搞反，或每次检查都重建频率数组，复杂度退化为 O(n²)。
6. 按位构造答案时没有从高位到低位贪心，而是逐位独立判断，得到的是不满足"包含所有已确定位"的假解。
