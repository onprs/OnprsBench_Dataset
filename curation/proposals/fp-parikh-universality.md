## 核心思想摘要

语言 $L(A,B,C)$ 固定词中 $a$、$b$ 的数量与 $ab$ 子序列的数量。词的普遍性指数等于 arch 分解中完整拱的个数；语言级指数由 $A$、$B$、$C$ 与 $AB-C$ 的一组阈值与整除条件精确决定，全部计算可在常数时间内完成。

## 参考解答要点

- canonical 结论：$\iota_{\exists} = \max\{k \le \min(A,B) : k(k-1)/2 \le \min(C, AB-C)\}$；$\iota_{\forall}$ 按定理 4.5 四档分类
- 关键证明思路（来源已发表）：存在方向由 $|w|_{ab} \ge \binom{k}{2}$ 与 $|w|_{ba} \ge \binom{k}{2}$ 的必要性与区间实现引理（引理 3.1、3.2）给出；全称方向对 8 个长度 3 模式逐一分析可避免性（引理 4.3）
- 已预见的 pitfalls：阈值差一、漏掉 $AB-C$、分档顺序、整除条件方向、大整数溢出
- 答案锚点核对说明：参考实现为定理的机械形式转换；已与独立暴力枚举在 $A,B \le 8$ 的全部 1377 组参数上逐字对拍一致
